# Shell Completion

`a2a completion` prints a completion script for bash, zsh, fish or PowerShell.

```bash
source <(a2a completion bash)    # or zsh
a2a completion fish | source
```

To load it in every shell, add the line to `~/.bashrc` or `~/.zshrc`. `a2a completion <shell> --help` shows how to install it permanently for each shell.
